One search.
Two ways in.

Same UX as v1: Home and Map read one shared query, type and time. v2 draws it with the app’s own parts: the paper band with the area chip, the dark photo hero, Browse-by-type tiles, v2.3 rows, Map E+ glass controls with price pins, and the dock.

Try this

  1. Clay magnifier = search (words). Sliders = Filters (type, price, sort) with a count badge. Both feed one shared state.
  2. Tap a result: the map opens on its price pin. The preview card always has Xem chi tiết, plus Giữ chỗ when the event is paid.
  3. Zoom out on the map (− or pinch): pins merge into neighbourhood bubbles, as in Map E+. Tap a bubble to fly in.
  4. Home live line: scrolls on its own, pause it with Trực tiếp, tap it for Đang diễn ra.
  5. Tất cả loại tile: pick e.g. Thời trang in the sheet and the tile becomes that type, selected.
