# Ngày 3 · Dữ liệu thật, trạng thái thật

**Lăng kính:** mỗi màn phải sống với dữ liệu thật và trạng thái xấu — trống, hết vé, huỷ, giữ chỗ hết hạn, khách chưa đăng nhập, host.

**Đọc trước:** `../decisions/day-03.json` · `../day-02-shell/<cụm>/index.html` + `../day-02-shell/shell.md`.

**Nộp:** `<cụm>/index.html` có bộ chuyển trạng thái (mỗi trạng thái một nút/URL) · `notes.md` ghi trạng thái nào lấy từ bản ghi thật nào (id + ngày) · `states.md` ở `day-03-states/` liệt kê trạng thái của cả 5 cụm.

**Xong khi:** không trạng thái nào là số bịa; trạng thái nào app chưa từng có thì ghi rõ là đề xuất mới.
