**Lăng kính:** chỉ review bản **đã chốt trong `../done/`** — không review bản nháp. Bản nháp là để thử; `done/` mới là
thứ đáng đưa vào app.

**Đọc trước:** `../decisions/day-08.json` (3 câu: `pick` · `apply` · `cadence`) · `../done/*/DECISION.md` ·
`../day-07-continuity/continuity.md` · `shell.md`, `states.md`, `motion.md`, `roles.md`, `devices.md` của các ngày ·
code thật (chỉ đọc) `src/`, `ios/`.

**Nộp:**

- `review.md` — bảng: cụm · trạng thái (sẵn sàng / cần sửa / bỏ) · file sẽ chạm · rủi ro · thứ tự. Mỗi mục "sẵn sàng"
  phải trỏ tới một folder cụ thể trong `done/`.
- `APPLY.discord.md` — **một** khối copy-paste cho cụm owner chọn ở câu `pick`: file:line, test phải chạy, cách
  rollback (sau một switch — `.claude/notes/30`), và điều **không** được đổi.

một phiên mới là chạy được, không cần hỏi lại.
