Before, the experience stopped at the ticket. Now every step has a clear moment, and the journey has an ending.

What a guest now sees

Reminders · live

"Your event is tomorrow" and "Starting soon" with the venue time and place. Shown in the app; also sent to the phone once push is on. People can turn each kind off.

Honest waiting · live

"The host checks the transfer and confirms. We'll notify you." Plus "This host usually confirms within about 30 minutes", only when the host has 5+ past confirmations.

After the event · live

"You went ✓" or "This event has ended", the event photos, a Follow button and up to 3 upcoming events by the same host.

Recap + private feedback · off

Thumbs up or down plus an optional note, sent privately to the host. The host only sees counts and unnamed notes, and only after 3 guests answered.

Weekend digest · off

"4 events this weekend, including Jazz Night." Only for people who opt in, Thursday about 18:00 their time, never when there is nothing to show.

Lock Screen card · off

On the iPhone, on event day: event name, start time and place on the Lock Screen. Created on the phone itself, no countdown.

Apple account and push: everything is ready except the key

Push notifications, the iPhone Lock Screen card and Apple Wallet all wait on the paid Apple Developer account. All the banbe-side work is done; these are the steps once you have the account. Full detail: docs/apple-setup-checklist.md.

1
Join the Apple Developer Program

USD 99 per year. Choose "Organization" to show "banbe" as the seller. Note the 10-character Team ID.

2
Turn on Push for the app

Developer website › Identifiers › com.banbe.ios › tick Push Notifications and Associated Domains.

3
Create a push key

Keys › + › Apple Push Notifications service › download the .p8 file (only once) and note the Key ID.

4
Hand the values to the systems

One command adds the Team ID to the app. Five settings go into Vercel (APNS_KEY_ID, APNS_TEAM_ID, APNS_BUNDLE_ID, APNS_PRIVATE_KEY, CRON_SECRET), and two lines are run once in Supabase.

5
Switch push on

In the app: Account › Admin › Feature switches › Push notifications.

6
Test on an iPhone

Sign in, open a confirmed ticket, allow notifications when banbe asks, then send yourself a message from another account.

Safe before the key

With the switch on but no key, the system only does a "dry run": it counts what it would send and sends nothing.

No flood later

Messages older than 15 minutes are dropped, so switching on later never sends a pile of old alerts.

Polite asking

banbe asks for permission only after someone has a confirmed ticket, with its own explanation first.
