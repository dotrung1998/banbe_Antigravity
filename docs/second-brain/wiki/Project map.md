# Project map

Where things live. Verified against the working tree on 2026-11-20; update it when a folder moves.

| Path | What it is |
| --- | --- |
| `src/` | Web app (React 19 + Vite). Screens in `src/screens`, shared parts in `src/components`, pure rules in `src/lib`. |
| `api/` | Vercel serverless functions (`cron`, `notify`, `media`, `wallet`, `payment-webhook`, `photo-share`, `calendar`, `dispute-resolved-email`, `payment-document`, `auth/`, `_lib/`). |
| `apps/ios/` | SwiftUI app, generated by XcodeGen — run `xcodegen generate` after pulling. |
| `supabase/migrations/` | The only source of schema truth. Applied with `supabase db push`; never edited after being applied. |
| `supabase/_localtest/` | Throwaway-Postgres harness; never deployed. |
| `tests/` | Playwright specs (`tests/public/…`) and `node --test` units (`tests/unit/…`). |
| `scripts/` | Build and ops scripts (`build-keychains.mjs`, `launchd/`, R2 migration). |
| `docs/` | Plans, runbooks, audits, prototypes. `docs/second-brain/` is this vault. |
| `.claude/notes/` | Numbered notes 01–101: the system of record for behaviour and stage status. |
| `CLAUDE.md` | Stage index, Baseline floor, and the project rules an agent must read first. |

## The three "is it real?" questions

1. **Is it applied?** Migrations are only real once `supabase db push` ran and a dated line exists in the production log.
2. **Is it deployed?** A merged commit is not a deploy; check the deploy, not the branch.
3. **Is it verified?** "Implemented locally" and "device-checked" are different states. The notes keep them separate on
   purpose — do the same in anything you write here.
